# RoomZA

RoomZA is a map-first rental discovery and application management app for the South African rental market.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- lucide-react

## Development

Install dependencies:

```bash
npm install
```

Run the local app shell:

```bash
npm run dev
```

Run checks:

```bash
npm run lint
npm run build
```
