# Public offer detail contract — 2 October 2026

The additive `/offers/[id]` page reads only the existing anonymous public DTO. It renders confirmed text without an image, the reviewed shop/address, terms, date window in SAST and optional everyone-visible poster attribution. It does not expose private drafts, authorization references, review notes, reviewer identities or removal reasons. Scheduled/expired results have no offer content; pending/withdrawn/removed/unknown links use the minimal unavailable state. Invalid identifiers do not reach the public reader. Metadata stays noindex until the broader public journey and release gates are ready.

Directions remain disabled until a fresh no-store browser read. The customer button then asks the existing server action endpoint for a fresh JSON destination. Ordinary endpoint navigation retains its existing redirect behavior. The server fixes the Google Maps host/path and uses the reviewed shop point, never the place centre or a visitor origin. The browser validates the bounded destination again before navigation. Every action rechecks current publication eligibility in the database.

Open-page expiry uses the database remaining time anchored conservatively at request start against monotonic browser time. It does not trust the device date. At expiry, terms and directions are removed immediately and current status is fetched; scheduled pages fetch at their start rather than inventing live content locally. A fifteen-second visible-page poll, visibility restoration and pageshow recheck status. A restored/hidden page disables directions until revalidated. Superseded requests are aborted and ignored. A refresh failure hides stale details, disables directions and provides explicit retry. Polling is an interface refresh; the action endpoint remains authoritative between refreshes.

This bounded detail slice does not add the offer Feed, Map, selected-area alternatives, saves, reports, activity or analytics. Its Return to Pinpoint link uses the existing home. Property routes, listingId and existing discovery/filter/favorite contracts remain unchanged. Synthetic browser checks do not establish real shop provenance or publishing permission. Shared runtime, staging, production and full Release 1 acceptance remain open.
