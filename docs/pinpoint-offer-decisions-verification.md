# Atomic private offer decisions — 2 October 2026

Approval, unpublication and atomic intake invalidation pass **13 real Auth/MFA/RPC/SQL checks on a disposable patched clone**. This implements persisted approval history; it adds no public read grants, customer surface or real supply. Cookie decision screens are next. Release acceptance stays 2/48.

Migration `20261002060000_pinpoint_offer_decisions.sql` adds private immutable decisions with actual actor/database time, captured/current version, revision, evidence IDs and final statement version. Approval locks/rechecks current membership/MFA, poster eligibility, exact pending/version, latest current-version permission/location evidence, locked catalogue equality and complete unexpired content. It atomically records approval, increments the offer version and clears the pending pointer. A scheduled start is permitted by the existing ordered-window validation.

An additive AFTER INSERT intake-event trigger invalidates an earlier approval in the same transaction as material submission or withdrawal. Private saves preserve the confirmed snapshot. Rejection after a material edit never restores it. Unpublication requires current MFA, revision/version and a private reason, and remains possible after poster eligibility is revoked. A fresh reviewed submission is needed to return. Stable request IDs deduplicate identical outcomes only while current; altered retries and intervening changes cannot revive them. Private decision reads require current MFA. The original schema/lifecycle/intake files, function bodies, grants and policies remain unchanged.
