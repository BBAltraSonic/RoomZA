# Scroll UX Audit

Scope: scrollable and persistent UI surfaces in `src/app`, `src/components`, and `src/features`. This is an interaction pass, not a visual redesign. Critical controls stay visible: chat composer, listing publish/save actions, active call controls, auth submit buttons, and destructive confirmations.

| Surface | Location | Current Behavior | Problems | Priority | Recommended Improvement | Trigger | Animation Spec | Reasoning | Accessibility Notes |
|---|---|---|---|---|---|---|---|---|---|
| Discovery desktop listings panel | `src/features/map-discovery/discovery-page.tsx` | Vertical panel with sticky header and horizontal card row | Header consumes space while browsing; filter context can feel heavy | High | Use shared adaptive chrome, compact filter density, contained vertical scroll | Down-scroll after 48px, restore on up-scroll, lock open on filters/sort/layers | Transform/opacity and padding, 180ms ease-out | More listing content fits without losing orientation | Preserve labels through `aria-label`; focus/open states force expanded |
| Discovery desktop list mode | `src/features/map-discovery/discovery-page.tsx` | Full-screen list over map | Same panel behavior needed in list mode | High | Reuse the same panel renderer and scroll state | Container scroll | Same as panel | Keeps map/list parity | Same filter lock behavior |
| Mobile discovery bottom sheet | `src/features/map-discovery/mobile/bottom-sheet.tsx` | Three snap positions with owned gesture math | Parent could not observe content scroll; nested scroll needs clear owner | High | Expose `onContentScroll`, keep one vertical owner, use contained overscroll | Expanded sheet body scroll | Existing snap transition remains | Preserves proven sheet math | Handle remains keyboard-resizable; body scroll only when expanded |
| Mobile list sheet | `src/features/map-discovery/discovery-page.tsx` | Full-screen listing sheet | Needs same adaptive header behavior as bottom sheet | High | Observe sheet body scroll and compact header/filter density | Body scroll | 180ms transform/opacity | Keeps search context while freeing space | Search/filter locks expand header |
| Listing carousel | `src/features/map-discovery/mobile/listing-carousel.tsx` | Horizontal snap row with dots | Discoverability and wheel behavior were limited | High | Add shared horizontal affordance, edge fades, progress, wheel-to-horizontal | Horizontal scroll | Progress transform, 120ms | Shows more content exists without noisy arrows | Native keyboard focus remains on cards |
| Property card image strip | `src/components/premium/property-card.tsx` | Snap image strip with desktop arrows | Edge affordance inconsistent with listing carousel | Medium | Add shared edge fade and wheel support | Horizontal scroll | Mask fade only | Standardizes card media behavior | Existing image buttons and save/call actions remain |
| Listing detail panel | `src/features/map-discovery/listing-detail-panel.tsx` | Header, image carousel, scroll body, pinned CTA | Decorative imagery competes while reading | High | Compact header and hide desktop hero imagery after deeper scroll | Detail body scroll | Transform/opacity and padding, 180ms | Prioritizes facts and CTA once reading starts | Apply/message footer remains visible |
| Chat thread | `src/features/chat/chat-box.tsx` | Always scrolls to bottom when messages change | Interrupts users reading older messages | High | Persist scroll, auto-scroll only near bottom, show newest jump when useful | Message list scroll and new messages | Static jump pill, no layout animation | Preserves reading position and speed to latest | Composer stays visible; live errors unchanged |
| Listing form progress nav | `src/features/listings/listing-form.tsx` | Sticky horizontal section nav | Takes vertical space on long forms | High | Compact sticky nav with progress bar on window scroll | Window scroll | Transform/padding, progress scaleX | Improves orientation without hiding publish actions | Publish/save footer remains sticky and safe-area aware |
| Dialogs | `src/components/ui/dialog.tsx` plus application/viewing/listing dialogs | Dialogs use max-height and internal scrolling per flow | Scroll containment and reduced motion were inconsistent | Medium | Add shared overscroll containment and reduced-motion-safe animation | Dialog open/close | Existing data animations, disabled under reduced motion | Prevents background scroll conflicts | Close control remains visible |
| Select menus | `src/components/ui/select.tsx` | Scrollable Base UI popups | Max-height and scrollbar styling inconsistent | Medium | Standard max-height, contained overscroll, hidden scrollbar | Menu open | Existing Base UI animation, disabled under reduced motion | Menus fit viewport and avoid scroll chaining | Base UI keyboard behavior preserved |
| Layer panel | `src/features/map-discovery/layer-toggle-panel.tsx` | Scrollable map overlay | Can compete with map controls | Medium | Keep contained scroll and lock discovery chrome while open | Panel open | No added motion | Layer state is task-critical context | Open state forces expanded discovery chrome |
| Messages overview | `src/app/messages/page.tsx` | Scrollable conversation list under persistent shell | Simple list, no adaptive chrome needed | Medium | Leave simple, retain contained list scrolling if revisited | List scroll | None | Restraint: no extra hints needed | Existing links and unread states remain |
| Applications and journey pages | `src/app/applications/page.tsx`, `src/app/journey/page.tsx`, `src/features/applications/journey/*` | Document-like app pages and boards | Long content can need orientation but not auto-hide | Low | Leave document pages simple; use future progress only if users lose position | Page scroll | None | Phase 14 restraint | Preserve keyboard navigation |
| Dashboard side nav and profile menu | `src/components/navigation/navigation.tsx`, `src/features/dashboard/workspace-nav.tsx` | Persistent global chrome | Task-critical navigation | Low | Document as persistent critical chrome; do not auto-hide globally | None | None | Avoids disorientation across app shell | Focus visibility unchanged |
| Auth forms | `src/app/auth/*` | Simple forms with submit actions | Submit controls are critical | Low | No adaptive hiding; only maintain overflow safety for Turnstile | None | None | Restraint and safety | Submit buttons remain visible |

Shared implementation added:

- `src/lib/scroll-adaptation.ts`: pure scroll state derivation with direction, velocity, progress, locks, reduced-motion handling, and `neverHidden`.
- `src/lib/hooks/use-scroll-adaptation.ts`: requestAnimationFrame-batched container measurement hook.
- `src/lib/hooks/use-scroll-position.ts`: lightweight session scroll restoration.
- `src/lib/hooks/use-horizontal-scroll-affordance.ts`: horizontal start/end/progress/wheel affordance.
- `src/app/globals.css`: contained scroll, edge fades, snap row, adaptive chrome, progress, and reduced-motion utilities.
