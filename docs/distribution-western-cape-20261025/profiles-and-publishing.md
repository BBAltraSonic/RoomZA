## Upload routine

The calendar uses **18:30 SAST** as an initial test time. This is an operational starting point, not a claim about peak audience activity. Compare actual local replies and enquiries after two weeks.

- **Tuesday:** supplied renter video. Facebook Reel, Instagram Reel, TikTok.
- **Thursday:** second supplied video. Same three destinations.
- **Saturday:** six-slide carousel on Facebook and Instagram.
- **Wednesday and Sunday:** one useful community contribution each, only where group rules permit it. No extra original video needed.

Each asset folder contains `caption-facebook-instagram.txt` and, for videos, `caption-tiktok.txt`. Upload the MP4 or numbered PNG slides, paste the matching caption, select the appropriate commercial-content disclosure, and review the crop and caption before publishing. Do not paste production notes or SRT text into a caption.

Schedule one week at a time. Keep the remaining weeks as drafts so current listings and readiness can determine the CTA. Use native scheduling or manual uploads if a format is unavailable on a free plan.

## Community selection

Use the shortlist to find candidates. Check the actual group and its rules while signed in: geographic relevance, room-rental relevance, recent genuine discussion, promotion/link rules, and whether Page participation is allowed. Select at most three appropriate groups initially. If rules prohibit promotional posts, contribute an answer without a Pinpoint CTA, or skip the group.

Do not buy access, bulk-message members or repost identical promotions across groups. The objective is two helpful contributions weekly. Record the source group code when someone voluntarily asks to learn more.
