description: Design or improve onboarding flows, empty states, and first-time user experiences
---

Create or improve onboarding experiences that help users understand, adopt, and succeed with the product quickly.

## Assess Onboarding Needs

1. **Identify the challenge**: What are users trying to accomplish? Where do they get stuck? What's the "aha moment"?
2. **Understand the users**: Experience level, motivation, time commitment?
3. **Define success**: Minimum users need to learn, key action to take?

**CRITICAL**: Get users to value as quickly as possible, not teach everything possible.

## Onboarding Principles

- **Show, Don't Tell**: Demonstrate with working examples
- **Make It Optional**: Let experienced users skip
- **Time to Value**: Front-load most important concepts
- **Context Over Ceremony**: Teach features when users need them
- **Respect User Intelligence**: Don't patronize or over-explain

## Design Onboarding Experiences

### Initial Product Onboarding
- Clear value proposition
- Minimal required information (collect more later)
- 1-3 core concepts (not everything)
- Guide users to accomplish something real
- Celebrate completion

### Feature Discovery & Adoption
- **Empty States**: Show what will appear, why it's valuable, clear CTA
- **Contextual Tooltips**: Appear at relevant moment, brief explanation, dismissable
- **Progressive Onboarding**: Teach features when encountered, unlock complexity gradually

### Guided Tours
- Spotlight specific UI elements
- 3-7 steps max per tour
- Interactive > passive
- Include "Skip tour" option

## Empty State Design

Every empty state needs:
1. **What Will Be Here**: Description
2. **Why It Matters**: Value proposition
3. **How to Get Started**: Clear CTA
4. **Visual Interest**: Illustration or icon
5. **Contextual Help**: Link to tutorial

**NEVER**:
- Force users through long onboarding before they can use product
- Show same tooltip repeatedly
- Block all UI during tour
- Create separate tutorial mode
- Hide "Skip" option
- Forget about returning users

## Verify Quality

- Can users complete onboarding quickly?
- Do users understand after completing?
- Do users take desired next step?
- Time to value?
