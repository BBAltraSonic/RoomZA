---
description: Strip designs to their essence by removing unnecessary complexity
---

Remove unnecessary complexity from designs, revealing essential elements and creating clarity through ruthless simplification.

## MANDATORY PREPARATION

Gather context: target audience, desired use-cases, what's truly essential vs nice-to-have. If unclear, ask the user directly before proceeding.

**CRITICAL**: Simplicity is not about removing features - it's about removing obstacles between users and their goals.

## Assess Current State

Identify complexity sources:
- **Too many elements**: Competing buttons, redundant information
- **Excessive variation**: Too many colors, fonts, sizes without purpose
- **Information overload**: Everything visible at once
- **Visual noise**: Unnecessary borders, shadows, decorations
- **Confusing hierarchy**: Unclear what matters most
- **Feature creep**: Too many options, actions, paths

Find the essence:
- What's the primary user goal? (ONE)
- What's actually necessary vs nice-to-have?
- What's the 20% that delivers 80% of value?

## Simplify the Design

### Information Architecture
- Remove secondary actions, optional features, redundant information
- Progressive disclosure: hide complexity behind clear entry points
- Combine related actions, group related content
- ONE primary action, few secondary, everything else tertiary or hidden

### Visual Simplification
- 1-2 colors plus neutrals (not 5-7)
- One font family, 3-4 sizes maximum, 2-3 weights
- Remove borders, shadows, backgrounds that don't serve function
- Flatten structure, reduce nesting - never nest cards inside cards

### Layout Simplification
- Linear flow: simple vertical flow where possible
- Full-width, generous white space
- Consistent alignment (pick left or center, stick with it)

### Interaction Simplification
- Fewer buttons, fewer options, clearer path
- Smart defaults, only ask when necessary
- ONE obvious next step, not five competing actions

### Content Simplification
- Cut every sentence in half, then do it again
- Active voice, plain language, remove jargon
- Essential information only
- Remove redundant copy (say it once)

**NEVER**:
- Remove necessary functionality
- Sacrifice accessibility
- Make things so simple they're unclear
- Eliminate hierarchy completely

## Verify Simplification

- **Faster task completion**: Can users accomplish goals more quickly?
- **Reduced cognitive load**: Is it easier to understand?
- **Still complete**: Are all necessary features accessible?
- **Clearer hierarchy**: Is it obvious what matters most?
