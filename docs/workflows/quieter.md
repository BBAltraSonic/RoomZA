---
description: Tone down overly bold or visually aggressive designs while maintaining quality
---

Reduce visual intensity in designs that are too bold, aggressive, or overstimulating, creating a more refined and approachable aesthetic.

## MANDATORY PREPARATION

Gather context: target audience, desired use-cases, brand personality/tone. If unclear, ask the user directly before proceeding.

**CRITICAL**: "Quieter" doesn't mean boring or generic. It means refined, sophisticated, and easier on the eyes.

## Assess Current State

Identify intensity sources:
- **Color saturation**: Overly bright or saturated colors
- **Contrast extremes**: Too much high-contrast juxtaposition
- **Visual weight**: Too many bold, heavy elements competing
- **Animation excess**: Too much motion or overly dramatic effects
- **Complexity**: Too many visual elements, patterns, decorations
- **Scale**: Everything is large and loud with no hierarchy

## Plan Refinement

- **Color approach**: Desaturate or shift to more sophisticated tones?
- **Hierarchy approach**: Which elements should stay bold (very few)?
- **Simplification approach**: What can be removed entirely?
- **Sophistication approach**: How to signal quality through restraint?

## Refine the Design

### Color Refinement
- Reduce saturation to 70-85%
- Replace bright colors with muted, sophisticated tones
- Use fewer colors more thoughtfully
- Let neutrals do more work, color as accent (10% rule)
- Use tinted grays instead of pure gray
- Never gray on color: use darker shade of background color or transparency

### Visual Weight Reduction
- Reduce font weights (900 → 600, 700 → 500)
- Use weight, size, and space instead of color and boldness
- Increase breathing room, reduce density
- Reduce border thickness, decrease opacity

### Simplification
- Remove decorative elements that don't serve purpose
- Simplify shapes, reduce border radius extremes
- Flatten visual hierarchy where possible
- Clean up blur effects, glows, multiple shadows

### Motion Reduction
- Shorter animation distances (10-20px instead of 40px)
- Remove decorative animations, keep functional motion
- Use ease-out-quart for understated motion (never bounce or elastic)
- Remove animations entirely if not serving a clear purpose

**NEVER**:
- Make everything the same size/weight (hierarchy still matters)
- Remove all color (quiet ≠ grayscale)
- Eliminate all personality
- Sacrifice usability for aesthetics

## Verify Quality

- **Still functional**: Can users accomplish tasks?
- **Still distinctive**: Does it have character?
- **Better reading**: Is text easier to read?
- **Sophistication**: Does it feel more refined and premium?
