Strategically introduce color to designs that are too monochromatic, gray, or lacking in visual warmth and personality.

## MANDATORY PREPARATION

Gather context: target audience, desired use-cases, brand personality/tone, and especially existing brand colors. If you can't fully infer, ask the user directly before proceeding.

## Assess Color Opportunity

1. **Understand current state**:
   - Pure grayscale? Limited neutrals? One timid accent?
   - Where could color add meaning, hierarchy, or delight?
   - Are there existing brand colors to use?

2. **Identify where color adds value**:
   - **Semantic meaning**: Success (green), error (red), warning (orange), info (blue)
   - **Hierarchy**: Drawing attention to important elements
   - **Categorization**: Different sections, types, or states
   - **Emotional tone**: Warmth, energy, trust

**CRITICAL**: More color ≠ better. Every color should have a purpose.

## Plan Color Strategy

- **Color palette**: 2-4 colors max beyond neutrals
- **Dominant color**: Which color owns 60%?
- **Accent colors**: 30% and 10% for contrast and highlights
- **Application strategy**: Where does each color appear and why?

## Introduce Color Strategically

### Semantic Color
- State indicators: Success green, error red, warning orange, info blue
- Status badges with colored backgrounds or borders
- Progress indicators

### Accent Color Application
- Primary actions: Color the most important buttons/CTAs
- Links: Add color to clickable text (maintain accessibility)
- Icons: Colorize key icons for recognition

### Background & Surfaces
- Replace pure gray with warm/cool tinted neutrals
- Colored sections to separate areas
- Subtle, intentional gradients (not generic purple-blue)

**Use OKLCH for color**: It's perceptually uniform.

### Borders & Accents
- Accent borders: Colored left/top borders to cards
- Focus rings matching brand
- Subtle colored dividers

## Balance & Refinement

### Accessibility
- Contrast ratios: WCAG compliance (4.5:1 for text, 3:1 for UI)
- Don't rely on color alone: Use icons, labels, or patterns alongside
- Test for color blindness

**NEVER**:
- Use every color in the rainbow
- Apply color randomly without semantic meaning
- Put gray text on colored backgrounds
- Use pure gray for neutrals (add subtle color tint)
- Default to purple-blue gradients (AI slop)
- Violate WCAG contrast requirements
