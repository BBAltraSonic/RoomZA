# Getting Started with Skills

## MANDATORY FIRST RESPONSE PROTOCOL

Before responding to ANY user message, complete this checklist:

1. List available skills/workflows in your mind
2. Ask yourself: "Does ANY skill match this request?"
3. If yes → Read the relevant workflow file
4. Announce which skill you're using
5. Follow the skill exactly

## Critical Rules

1. **Follow mandatory workflows.** Check for relevant skills before ANY task.
2. If a skill for your task exists, you must use it.

## Common Rationalizations That Mean You're About To Fail

- "This is just a simple question" → Check for skills
- "This doesn't need a formal skill" → If a skill exists, use it
- "The skill is overkill for this" → Skills exist because simple things become complex
- "I'll just do this one thing first" → Check for skills BEFORE doing anything

## Skills with Checklists

If a skill has a checklist, create todos for EACH item. Don't work through checklists mentally.

## Announcing Skill Usage

Before using a skill, announce it:
"I'm using [Skill Name] to [what you're doing]."

## Summary

1. If relevant skill exists → Use it
2. Announce you're using it
3. Follow what it says
4. Skill has checklist? → Todos for every item
