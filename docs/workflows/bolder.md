description: Amplify safe or boring designs to make them more visually interesting and stimulating

Increase visual impact and personality in designs that are too safe, generic, or visually underwhelming.

## MANDATORY PREPARATION

Gather context: target audience, desired use-cases, brand personality/tone. If you can't fully infer, ask the user directly before proceeding.

**WARNING - AI SLOP TRAP**: When making things "bolder," avoid the tired tricks: cyan/purple gradients, glassmorphism, neon accents on dark backgrounds, gradient text. Bold means distinctive, not "more effects."

## Assess Current State

Analyze what makes the design feel too safe:
- **Generic choices**: System fonts, basic colors, standard layouts
- **Timid scale**: Everything is medium-sized with no drama
- **Low contrast**: Everything has similar visual weight
- **Static**: No motion, no energy
- **Predictable**: Standard patterns with no surprises

## Plan Amplification

- **Focal point**: What should be the hero moment? (Pick ONE)
- **Personality direction**: Maximalist chaos? Elegant drama? Playful energy?
- **Hierarchy amplification**: Make big things BIGGER, small things smaller

## Amplify the Design

### Typography Amplification
- Replace generic fonts with distinctive choices
- Extreme scale jumps (3x-5x differences, not 1.5x)
- Weight contrast: Pair 900 with 200 weights

### Color Intensification
- Increase saturation to more vibrant colors (but not neon)
- Bold palette with unexpected combinations
- Dominant color strategy: one bold color owns 60%
- Tinted neutrals instead of pure grays

### Spatial Drama
- Extreme scale jumps for important elements
- Break the grid: Let hero elements escape containers
- Asymmetric layouts with tension
- Generous space (100-200px gaps, not 20-40px)

### Visual Effects
- Dramatic shadows for elevation
- Background treatments: mesh patterns, noise textures, geometric patterns
- Texture & depth: Grain, halftone, duotone

### Motion & Animation
- Entrance choreography: Staggered, dramatic page load animations
- Scroll effects: Parallax, reveal animations
- Smooth transitions using ease-out-quart/quint/expo (never bounce or elastic)

**NEVER**:
- Add effects randomly without purpose
- Sacrifice readability for aesthetics
- Make everything bold (need contrast)
- Ignore accessibility
- Copy trendy aesthetics blindly

## Verify Quality

- **NOT AI slop**: Does this look like every other AI-generated design? If yes, start over.
- **Still functional**: Can users accomplish tasks?
- **Coherent**: Does everything feel intentional?
- **Memorable**: Will users remember this?
